Exploratory Analysis: Distributions, Odd Rows and Real Differences

Both notebooks work on one brief: someone upstairs wants to know which musical qualities make a track popular, so the label can commission more of them. The answer turns out to be none of them, and getting to a well-supported no is most of what we do this week. Along the way: what a mean hides, rows that cannot be right, t-tests, ANOVA, chi-square, effect size, and why the strongest relationship in the file is one nobody can act on.

Continues from session 02

Same Spotify file, same row meaning. No joins this week: every audio measurement is already on every row, so the setup is two lines. There is deliberately less code than last session and more time to talk about what the output means. The track IDs are real Spotify IDs, so the notebooks link straight to the songs and we will play a few of them.

By the end of the session

  • Read a distribution and say what a mean is hiding.
  • Find rows that cannot be right, and decide what to do about them out loud.
  • Report a correlation with a picture next to it, and say which numbers are findings.
  • Run a t-test, a one-way ANOVA and a chi-square test, and interpret each one correctly.
  • Separate a significant difference from one that is large enough to matter, using effect size.
  • Ask which way the arrow points before reporting a relationship, and spot the ones that run backwards.
  • Write up a result that says no, with the same confidence as one that says yes.
  • Report a comparison as size, counts and p value, in that order.

Reading and reference

Student reference: what each test answers, and how to report it

If you want one idea to take away, take this one: a p value tells you whether a difference exists given your sample size. It says nothing about whether it is big enough to care about, and nothing about which way the arrow points.
